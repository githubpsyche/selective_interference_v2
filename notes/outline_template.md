Yes: the outline template should shift from a generic “review paragraph” template to a “warrant one part of the opening map” template.

For each body paragraph, use:

```markdown
Paragraph N: [Mechanism/regularity name]

Opening-map role:
Which already-introduced part of the trauma-film mapping this paragraph earns.
Example: representing film/task/delay as one context stream; treating task events as recall candidates; implementing reminders as context reinstatement; treating recognition as supplied-item access.

Paragraph claim:
The one sentence this paragraph should establish.

Motivating empirical regularities:
The empirical pattern that makes this mechanism worth including.
Citations: [plural citations]

Modeling proposal:
The retrieved-context/CMR/eCMR operation motivated by those regularities.

How the proposal explains the regularities:
The causal/computational link, stated plainly.

Selective-interference payoff:
What this operation contributes to the account of reminder-linked task interference.

Figure role:
Whether this paragraph introduces, previews, recalls, or cashes out a figure/panel.

Boundary:
What this paragraph should not try to do because it belongs elsewhere.
```

For subsections, use:

```markdown
## [Exact Subsection Heading]

Local thesis:
One sentence stating the theoretical proposal represented by the subsection.

Opening-map dependency:
Which part of the section-opening map the subsection develops.

Exact orienting opening:
Draft text.

Body paragraph plan:
Use the paragraph template for each paragraph.

Figure role:
Which figure/panel carries the subsection’s argument, and whether the figure is introduced here or recalled from the opening.

Exact closing/payoff:
Draft text that states what the subsection has now earned.

Transition:
Draft text explaining why the next subsection follows.
```

For the whole section, use:

```markdown
# A Retrieved-Context Account of Selective Interference

Section role:
Framework-warrant section, not model specification.

Exact opening paragraphs:
Draft text that maps the trauma-film paradigm into retrieved-context terms.

Opening map commitments:
1. Film/task/delay are event sequences in one evolving context stream.
2. Film reminders reinstate film-associated context before task encoding.
3. Task events encoded in that state can later be sampled with film material.
4. Retrieval determines how strongly task competitors are expressed.
5. Figures 3 and 4 summarize encoding and retrieval operations.

Subsections:
Use subsection template.

Exact closing paragraphs:
Draft text that states what has been warranted and hands off to model specification.
```

The key addition is `Opening-map role`. That forces every paragraph to earn a specific part of the setup rather than merely “connect back” in a loose final sentence.
