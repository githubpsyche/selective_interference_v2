Yes. Benjamin is memory-specific, but not the most canonical source for the general inference problem.

For the current draft, I’d rank them this way:

1. **Newell & Dunn (2008)**  
   Best compact citation for the general methodological point: dissociation logic is a weak basis for inferring latent dimensions/processes; state-trace/model-based analysis is stronger.  
   Use if you want one broad, readable citation.  
   Source: [Newell & Dunn, 2008](https://www.sciencedirect.com/science/article/abs/pii/S1364661308001526)

2. **Dunn & Kirsner (1988)**  
   Classic source arguing that ordinary functional dissociations are not the strongest evidence for independent processes; they propose “reversed association” as a stronger basis.  
   Use if you want the older foundational citation.  
   Source: [Dunn & Kirsner, 1988](https://research-repository.uwa.edu.au/en/publications/discovering-functionally-independent-mental-processes-the-princip/)

3. **Dunn & Kirsner (2003)**  
   Directly on “what can we infer from double dissociations?” More on the logic of double dissociation in cognitive/neuropsychological inference.  
   Use if the sentence explicitly mentions double dissociations or architectural inference.  
   Source: [Dunn & Kirsner, 2003](https://pubmed.ncbi.nlm.nih.gov/12627749/)

4. **Plaut (1995)**  
   Strong computational-modeling precedent: a double dissociation can arise in a connectionist system without modular architecture.  
   Use if you want a close analogy to “a formal model can reproduce a dissociation without the architecture usually inferred from it.”  
   Source: [Plaut, 1995](https://pubmed.ncbi.nlm.nih.gov/7629273/)

5. **Benjamin (2010)**  
   Best memory-domain example: recognition-memory “process” dissociations can be explained representationally.  
   Use if you want a memory-specific analogy, but I would not make it the only support.  
   Source: [Benjamin, 2010](https://pmc.ncbi.nlm.nih.gov/articles/PMC3045270/)

My recommendation for the current draft: cite **Newell & Dunn (2008)** plus **Benjamin (2010)** if you make the general point in the introduction. Add **Plaut (1995)** only if you want to emphasize the computational-modeling precedent.
