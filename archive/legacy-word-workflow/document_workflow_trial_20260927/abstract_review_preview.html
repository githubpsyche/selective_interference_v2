Memory theory must explain what distinguishes deliberate from involuntary retrieval. Studies using the trauma-film paradigm show that an imagery-competing task performed after a film reminder can reduce later intrusions while leaving voluntary memory relatively intact. This selective interference effect is often interpreted through clinical theories of traumatic memory in which intrusive and voluntary remembering depend on different memory representations. Here we show how the same dissociation can arise from retrieval processes operating on the same learned associations. We develop this account in an emotional Context Maintenance and Retrieval (eCMR) model that predicts sequences of film and non-film recall events. In the model, experiences encoded while a context state is active become associated with that context and can later be cued together. A film reminder reinstates film-associated context before the task, so imagery generated during the task becomes associated with that context. That context can later cue competing memories of both the task and the film. In the simulations, task memories interfered less with deliberate film recall than with involuntary retrieval only when a maintained cue favored film memories over task memories. These results motivate tests of how competitor learning and retrieval goals shape selective interference in standard episodic memory paradigms.
