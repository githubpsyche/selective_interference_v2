\abstract{In the trauma-film paradigm, a visuospatial task after a later
film reminder can reduce the frequency of film intrusions while leaving
voluntary memory relatively intact. This selective interference effect
is often treated as evidence that involuntary and deliberate remembering
depend on different memory representations. We propose instead that the
dissociation can reflect differences in how retrieval is cued and
controlled. We implement this account in an emotional Context
Maintenance and Retrieval (eCMR) model that simulates film, reminder,
and task encoding and predicts sequences of film and non-film recall
events. In the model, a film reminder reinstates film-associated context
before the task. Task items are then encoded in association with that
context, so later film-associated context can cue task competitors as
well as film items. Deliberate recall is less affected when a maintained
film-retrieval goal gives film candidates an additional source of
support without equally supporting task competitors. In tasks like
recognition, the test presents the item, so the model evaluates the
item's fit to context instead of selecting among film and task
candidates. This comparison can therefore make voluntary memory appear
spared because of test format rather than because voluntary remembering
is generally unaffected. Interpreting selective interference this way
motivates better-matched tests of intrusive and voluntary remembering
and situates trauma-film findings within a broader computational account
of episodic retrieval. }

\keywords{intrusive memories, voluntary memory, trauma-film
paradigm, visuospatial intervention, selective
interference, retrieved-context theory, computational modeling}

\section{Introduction}\label{introduction}

Traumatic experience foregrounds a tension between durability and
selectivity in episodic memory. From a functional perspective, events
with lasting significance need to remain accessible in memory so
remembered details can guide later decisions
(\citeproc{ref-zhou2025episodic}{Zhou et al., 2025}). At the same time,
adaptive retrieval is selective: what comes to mind should normally
depend on current goals, cues, and circumstances. Intrusive memories
after trauma suggest that durable memory can strain the selectivity of
retrieval. In PTSD, such memories can come to mind unbidden and poorly
matched to the present, causing distress and interfering with ongoing
activity (\citeproc{ref-brewin2010intrusive}{Brewin et al., 2010};
\citeproc{ref-ehlers2000cognitive}{Ehlers \& Clark, 2000};
\citeproc{ref-iyadurai2019intrusive}{Iyadurai et al., 2019};
\citeproc{ref-krans2009intrusive}{Krans et al., 2009}). Explaining how
episodic memory preserves consequential events while regulating their
retrieval is therefore a shared target for both clinical science and
mechanistic theories of memory.

The trauma-film paradigm provides a controlled setting for comparing
intrusive and voluntary memory for the same event
(\citeproc{ref-holmes2008inducing}{Holmes \& Bourne, 2008};
\citeproc{ref-james2016trauma}{James et al., 2016}). Participants view
distressing film material, record later intrusive memories of the film,
and often complete voluntary-memory tests for the same material. This
design makes it possible to ask whether the same encoded event can
remain available to deliberate retrieval while becoming more or less
likely to come to mind involuntarily. In such research, intrusion
frequency is often only weakly related to voluntary-memory performance,
such that the two measures dissociate
(\citeproc{ref-holmes2004trauma}{Holmes et al., 2004};
\citeproc{ref-james2016trauma}{James et al., 2016}). The same encoded
episode can therefore support both involuntary and deliberate access,
and these modes can come apart empirically.

Visuospatial interference tasks make this dissociation experimentally
sharper. In immediate post-film studies, tasks such as Tetris can reduce
later film intrusions while voluntary memory for the same material
remains relatively intact (\citeproc{ref-deeprose2012imagery}{Deeprose
et al., 2012}; \citeproc{ref-holmes2009can}{Holmes et al., 2009},
\citeproc{ref-holmes2010key}{2010};
\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019}). Delayed variants
pair the interference task with a film reminder. Participants return
after roughly 24 hours to 3 days, view reminder cues for the film, and
then complete Tetris. This reminder-plus-Tetris sequence can reduce
subsequent intrusions (\citeproc{ref-james2015computer}{James et al.,
2015}; \citeproc{ref-kessler2020visuospatial}{Kessler et al., 2020}).
Related procedures have been extended beyond analogue trauma films to
real-life and occupational trauma, including motor vehicle accidents,
emergency caesarean section, refugee trauma, and health-care work during
COVID-19 (\citeproc{ref-beckenstrom2026digital}{Beckenstrom et al.,
2026}; \citeproc{ref-horsch2017reducing}{Horsch et al., 2017};
\citeproc{ref-iyadurai2018preventing}{Iyadurai et al., 2018},
\citeproc{ref-iyadurai2023reducing}{2023};
\citeproc{ref-kanstrup2021single}{Kanstrup et al., 2021},
\citeproc{ref-kanstrup2024guided}{2024};
\citeproc{ref-ramineni2023treating}{Ramineni et al., 2023}). At the same
time, recent reviews and replication attempts caution against treating
the effect as settled or uniform
(\citeproc{ref-asselbergs2023systematic}{Asselbergs et al., 2023};
\citeproc{ref-mcconnell2026testing}{McConnell et al., 2026};
\citeproc{ref-varma2024experimental}{Varma et al., 2024};
\citeproc{ref-wessel2025evidence}{Wessel et al., 2025}). This selective
interference effect therefore raises a theoretical question: when and
why can an intervention alter intrusion-like and voluntary access
differently, even when both concern the same recent experience?
Figure~\ref{fig-empirical-target} summarizes the modeled contrast: a
reminder-linked interference task should reduce intrusion-like film
access more than voluntary film recall.

The selective interference effect has been used to argue that intrusive
and voluntary remembering depend on differently vulnerable memory
representations (\citeproc{ref-brewin1996dual}{Brewin et al., 1996};
\citeproc{ref-brewin2014episodic}{Brewin, 2014}). Dual-representation
accounts give this interpretation an architectural basis. Intrusive
re-experiencing is linked especially to sensory-bound representations,
whereas deliberate remembering depends more on contextualized episodic
representations (\citeproc{ref-brewin2010intrusive}{Brewin et al.,
2010}; \citeproc{ref-brewin2014episodic}{Brewin, 2014}). In immediate
post-film interventions, visuospatial tasks are understood to compete
for working-memory resources while sensory-perceptual imagery from the
film is still being maintained and consolidated
(\citeproc{ref-baddeley2000working}{Baddeley \& Andrade, 2000}). Because
later intrusions are assumed to arise especially from sensory-bound
representations, the selective pattern is attributed to disrupting the
representation most likely to support intrusions while leaving
voluntary-memory performance relatively preserved
(\citeproc{ref-deeprose2012imagery}{Deeprose et al., 2012};
\citeproc{ref-holmes2009can}{Holmes et al., 2009},
\citeproc{ref-holmes2010key}{2010};
\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019}). In delayed
post-reminder interventions, the reminder is instead treated as
reactivating the relevant memory before the task, allowing the
interference procedure to alter later availability through
reconsolidation or post-reactivation updating
(\citeproc{ref-james2015computer}{James et al., 2015};
\citeproc{ref-kindt2009beyond}{Kindt et al., 2009}). Across these
variants, selectivity is explained as a stronger effect on the memory
basis for intrusions than for voluntary remembering.

Here we argue that preserved voluntary memory does not, by itself,
establish that a separate representation was spared. Selective
interference can instead arise from differences in how film memories are
cued and controlled at retrieval. In the account developed below, a film
reminder reinstates context associated with the film before task
material is encoded. Task material then becomes linked to that context.
When later remembering is guided by film-associated context, task and
film material can therefore compete, interfering with film recall. The
task interferes less when retrieval depends less on context to access
film material. Deliberate recall can be less affected when a maintained
film-retrieval goal gives film candidates an additional source of
support without equally supporting task competitors. Tasks like
recognition can also be less affected, because the test presents a
candidate film item for judgment rather than requiring film material to
be brought to mind. On this account, the selective-interference effect
emerges when retrieval conditions differ in how much they depend on
film-associated context that also cues task material.

We formalize this retrieval account in an emotional variant
(\citeproc{ref-cohen2022memory}{Cohen \& Kahana, 2022};
\citeproc{ref-talmi2019retrieved}{Talmi et al., 2019}) of the Context
Maintenance and Retrieval (CMR) model
(\citeproc{ref-polyn2009context}{Polyn et al., 2009a}).
Retrieved-context models treat context as a gradually changing state
that is shaped by experience, reinstated by retrieval, and used to cue
later memory search (\citeproc{ref-howard2002distributed}{Howard \&
Kahana, 2002}; \citeproc{ref-polyn2009context}{Polyn et al., 2009a};
\citeproc{ref-sederberg2008context}{Sederberg et al., 2008}). In CMR,
items and context are linked by bidirectional associations. Context cues
candidate items, and retrieved items or items presented at test
reinstate associated context (\citeproc{ref-polyn2009context}{Polyn et
al., 2009a}, \citeproc{ref-polyn2009task}{2009b}). Emotional CMR
variants retain this item-context architecture while allowing emotional
or source context to shape what is bound and later retrieved
(\citeproc{ref-cohen2022memory}{Cohen \& Kahana, 2022};
\citeproc{ref-talmi2019retrieved}{Talmi et al., 2019}). These properties
make CMR a principled setting for a retrieved-context account of
selective interference based on context reinstatement and item-context
binding.

Applied to the trauma-film paradigm, the model treats film,
delay-period, task, and filler events as a continuous sequence through
which context evolves. A film reminder is implemented as item-to-context
reinstatement before task encoding. Later recall is implemented as
context-to-item sampling from the film and non-film items supported by
the current retrieval state. When that context supports both film and
task material, task items compete with film recall rather than merely
weakening a film trace.

Deliberate recall is modeled with several retrieval-control processes.
Rather than universally protecting film recall in a manner consistent
with the selective interference effect, we show that some control
mechanisms can increase film recall without making recall less sensitive
to reminder-linked task encoding. In the simulations, the strongest
protection comes from adding a maintained film-retrieval goal that gives
film candidates support not shared by task competitors. This identifies
a functional condition for selective interference: voluntary recall is
protected when it depends less on film-associated temporal context that
has also become supportive of task material.

The simulations follow a generalization-style modeling logic
(\citeproc{ref-busemeyer2000model}{Busemeyer \& Wang, 2000};
\citeproc{ref-lohnas2023event}{Lohnas et al., 2023}). We anchor core
eCMR parameters in an independent affective free-recall dataset
(\citeproc{ref-dupertuys2026ukraine}{Dupertuys et al., 2026}), then map
the trauma-film sequence onto that architecture and ask whether it
produces the qualitative selective-interference pattern. The first
simulations examine whether reminder-linked task encoding creates
competitors for film recall. The next simulations ask when deliberate
recall is protected from those competitors, focusing on whether a
maintained film-retrieval goal gives film material a more selective
basis for recall. A final recognition analysis treats recognition as a
boundary condition: when a candidate film item is supplied for judgment,
performance need not depend on sampling that item from a context that
also cues task material. Together, the simulations define a mechanistic
alternative to selective-vulnerability accounts and identify conditions
under which intrusive and voluntary remembering should appear more or
less dissociated.

\subsection{Retrieval Conditions in Selective
Interference}\label{retrieval-conditions-in-selective-interference}

Figure~\ref{fig-empirical-target} summarizes the selective interference
effect as reduced intrusion-like access with relatively preserved
voluntary memory for the same film material. Studies of this effect use
tests that differ in whether film content must be generated or is
presented for judgment. Diary measures attempt to count film memories
that inadvertently arise during daily life. Laboratory intrusion tasks
count memories reported during a defined monitoring period, sometimes
while film cues are present. Recognition tests present candidate film
statements or still images for judgment. Free recall and retrieval probe
tasks require participants to produce or elaborate film details from a
prompt (\citeproc{ref-holmes2008inducing}{Holmes \& Bourne, 2008};
\citeproc{ref-james2016trauma}{James et al., 2016};
\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019},
\citeproc{ref-lau2021selectively}{2021}). The resulting comparisons
differ in whether film content is already supplied or has to come to
mind.

Many studies that established selective interference used recognition as
the voluntary-memory test. Immediate post-film Tetris studies and
delayed reminder-plus-Tetris studies report fewer diary or laboratory
intrusions while verbal or visual recognition remains similar across
groups (\citeproc{ref-holmes2009can}{Holmes et al., 2009},
\citeproc{ref-holmes2010key}{2010};
\citeproc{ref-james2015computer}{James et al., 2015};
\citeproc{ref-kessler2020visuospatial}{Kessler et al., 2020}). Later
diary-recognition work uses the same basic pairing
(\citeproc{ref-asselbergs2024effectiveness}{Asselbergs et al., 2024}).
Those results show that the intervention can reduce film memories
reported as intrusions while leaving participants able to recognize
candidate film material at test. Later studies made the concern more
specific: diary reports depend on film memories coming to mind, whereas
recognition tests supply candidate film material for judgment
(\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019},
\citeproc{ref-lau2021selectively}{2021}). Preserved recognition is
therefore narrower than general preservation of voluntary memory.
Reviews, replication attempts, and newer tests also caution against
treating the effect as uniform
(\citeproc{ref-asselbergs2023systematic}{Asselbergs et al., 2023};
\citeproc{ref-hemi2023cognitive}{Hemi et al., 2023};
\citeproc{ref-mcconnell2026testing}{McConnell et al., 2026};
\citeproc{ref-varma2024experimental}{Varma et al., 2024};
\citeproc{ref-wessel2025evidence}{Wessel et al., 2025}).

Studies using recall, probing, or vigilance-intrusion measures test
whether the dissociation persists when film material has to be produced
or reported under more closely matched conditions. One three-experiment
study added free recall, specific probing, and priming to the
diary-recognition comparison, then introduced a vigilance-intrusion task
to measure intrusions during a laboratory monitoring task
(\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019}).
Reminder-plus-Tetris reduced diary and vigilance intrusions while free
recall, specific probing, and recognition were relatively preserved.
Later work matched vigilance-intrusion and modified recognition measures
more closely in cueing, context, timing, and attentional demands, again
finding reduced intrusion measures with preserved recognition
(\citeproc{ref-lau2021selectively}{Lau-Zhu et al., 2021}). A recent
preregistered study pushed the matching further by using voluntary and
involuntary versions of the same vigilance retrieval task, but did not
find the predicted reduction in involuntary memory
(\citeproc{ref-mcconnell2026testing}{McConnell et al., 2026}).
Vigilance-intrusion tasks bring intrusion measurement into the
laboratory. Participants perform an ongoing task and report film
memories that arise, sometimes while film cues are presented. These cues
can prompt retrieval of film memories, but they do not supply the
candidate film item for recognition. Vigilance-retrieval variants extend
this logic by using similar task structure for voluntary and involuntary
reports, changing the retrieval instruction while keeping cue timing,
task context, and response format more closely matched
(\citeproc{ref-mcconnell2026testing}{McConnell et al., 2026}).

Figure~\ref{fig-empirical-examples} illustrates this empirical range
with three exemplar designs: delayed-reminder diary-plus-recognition,
delayed-reminder diary-plus-free-recall, and trauma-film-cued
vigilance-intrusion-plus-recognition.

Panel A of Figure~\ref{fig-empirical-target} defines the target paradigm
for the trauma-film recall simulations: film encoding, a possible
reminder, task encoding, and later unguided or deliberate retrieval that
can produce sequences of film and non-film recall events. The unguided
retrieval condition approximates laboratory intrusion measurement rather
than recognition. Film cues can be present during a monitoring task, but
the film item still has to be sampled and reported if it comes to mind.
Recognition is a boundary condition because the candidate film item is
already present at test. When a test supplies the item for judgment,
memory can succeed through an item-to-context route rather than through
sampling from the current retrieval state. The retrieved-context account
therefore has to explain why reminder-linked task material can compete
with film recall during vigilance-intrusion retrieval while recognition
remains relatively preserved.

\section{A Retrieved-Context Account of Selective
Interference}\label{a-retrieved-context-account-of-selective-interference}

\newpage{}

\begin{figure}[H]

\caption{\label{fig-retrieved-context-encoding-associations}\textbf{Encoding
and associative structure in the retrieved-context account.}
\textbf{(A)} The model stores bidirectional item-context associations.
Context-to-feature associations cue candidate items from the current
context, and feature-to-context associations reinstate context when an
item is recalled or when a reminder or test cue is presented.
\textbf{(B)} The interference manipulation changes which context states
task items are linked to during encoding. Without a pre-task reminder,
task items are encoded after context has drifted away from the film.
With a pre-task film reminder, task encoding occurs after
film-associated context has been reinstated, so task items are learned
in context states that overlap with film context. Thus, the same context
that can cue film items can also cue task competitors during later
retrieval. When task encoding is strong, those task items become
stronger competitors during later context-guided retrieval. Circles mark
item features: F labels film items and T labels task items. Squares mark
context states. Blue marks film items or film-linked context, orange
marks task items or task-linked context, green marks reminder cues, and

Retrieved-context models explain recall as search from a changing
context state shaped by recent experience and prior retrieval. The
current context cues candidate items, and recalled items reinstate
context from encoding, producing temporal organization in free recall
(\citeproc{ref-howard2002distributed}{Howard \& Kahana, 2002};
\citeproc{ref-sederberg2008context}{Sederberg et al., 2008}). Applied to
selective interference, these operations explain how task material
becomes linked to film-associated context and how later retrieval
determines the extent to which that material competes with film material
for recall.

Film, task, and delay periods are represented as sequences of events
that update context. For the film, these events correspond roughly to
scenes or segments. For the task and delay periods, they represent
non-film events that can also be encoded and later sampled. A film
reminder reinstates film-associated context before task encoding. Task
events encoded in that state can later be cued alongside film material.
Retrieval then depends on how strongly the test setting constrains
search toward film material rather than toward the broader set of
candidates supported by the current context.
Figure~\ref{fig-retrieved-context-encoding-associations} summarizes the
encoding and associative structure of the account, and
Figure~\ref{fig-retrieved-context-retrieval-operations} summarizes the
retrieval operations.

\subsection{Context-Guided Search and Source
Organization}\label{context-guided-search-and-source-organization}

Retrieved-context models were developed to explain structured
regularities in open-ended recall. Free recall favors recently studied
items, and successive recalls tend to come from nearby study positions
(\citeproc{ref-howard2002distributed}{Howard \& Kahana, 2002};
\citeproc{ref-kahana1996associative}{Kahana, 1996};
\citeproc{ref-sederberg2008context}{Sederberg et al., 2008}). In these
models, a gradually changing context state cues candidate items, and
recalled items reinstate the contexts in which they were encoded.
Recency follows because the retrieval context remains similar to
contexts from recent study and recall events. Temporal contiguity
follows because a recalled item reinstates context from its study
position, which is similar to the contexts associated with nearby items.

Recall is also organized by shared content, task, and source.
Semantically related items, items encoded under the same task, and items
from the same source can cluster during recall
(\citeproc{ref-lohnas2023event}{Lohnas et al., 2023};
\citeproc{ref-morton2016predictive}{Morton \& Polyn, 2016};
\citeproc{ref-polyn2009context}{Polyn et al., 2009a},
\citeproc{ref-polyn2009task}{2009b},
\citeproc{ref-polyn2012neural}{2012}). CMR captures this broader
organization by allowing semantic, task, and source information to
contribute to the context state that guides retrieval. Items that share
these forms of context can support one another during memory search even
when temporal position alone would not explain the organization. In an
account of the trauma-film paradigm, this lets film material receive
shared film-directed support while individual film scenes or segments
remain distinct encoded events.

Emotional memory gives source organization a further role in the present
model. Emotional items can cluster together, and emotional material is
often remembered better than neutral material
(\citeproc{ref-talmi2007contribution}{Talmi et al., 2007};
\citeproc{ref-talmi2013enhanced}{Talmi, 2013};
\citeproc{ref-talmi2004semantic}{Talmi \& Moscovitch, 2004}). Emotional
CMR represents affective information as a source-like context dimension
and allows emotional items to form stronger source-context associations
(\citeproc{ref-cohen2022memory}{Cohen \& Kahana, 2022};
\citeproc{ref-talmi2019retrieved}{Talmi et al., 2019}). The same
architecture can therefore give trauma-film material a shared
film-directed signal and stronger retrieval support, while leaving
neutral task and delay material available as separate competitors.

\subsection{Reminder-Linked Competitor
Encoding}\label{reminder-linked-competitor-encoding}

Reminder-linked task interventions produce interference by changing what
task events become associated with during encoding. In a
retrieved-context account, task events interfere with film recall when
they are encoded in context states that later also support film
material.

A film reminder can change the context in which the later task is
encoded. In retrieved-context models, presented or retrieved items can
reinstate context from encoding
(\citeproc{ref-howard2002distributed}{Howard \& Kahana, 2002};
\citeproc{ref-polyn2009context}{Polyn et al., 2009a};
\citeproc{ref-sederberg2008context}{Sederberg et al., 2008}). When a
film cue is presented before the task, it shifts current context toward
states associated with the earlier film episode. Task events are then
encoded in a context that can later also support film material.

Recall can include material outside the intended target. In multi-list
free recall, participants sometimes report items from earlier lists
instead of the list they were asked to recall
(\citeproc{ref-howard2008persistence}{Howard et al., 2008};
\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015};
\citeproc{ref-zaromb2006temporal}{Zaromb et al., 2006}). Those errors
are structured: they are biased toward recently studied prior lists and
change as intervening study or delay changes. Retrieved-context models
explain this pattern by treating recall as candidate sampling from the
current context. As context drifts, support for non-target items
declines. When a non-target item was encoded in a recent or related
context, it can still enter the candidate set. This makes task and delay
events eligible recall candidates in the trauma-film paradigm. If those
events are encoded in context states that later support film recall,
they can compete with film material during retrieval.

Delayed reminder-linked task interventions in the trauma-film paradigm
instantiate this kind of competitor encoding. In these studies,
participants encounter film cues before the interference task, and the
procedure is typically interpreted as reactivating film memory before
the task begins (\citeproc{ref-james2015computer}{James et al., 2015};
\citeproc{ref-kessler2020visuospatial}{Kessler et al., 2020}). When
participants return to an earlier learning context, new material can
become linked to the earlier episode
(\citeproc{ref-hupbach2008dynamics}{Hupbach et al., 2008};
\citeproc{ref-sederberg2011human}{Sederberg et al., 2011}). The
simulations instantiate this sequence by placing task encoding after
reminder-driven reinstatement of film-associated context. Task events
encoded in that reinstated state acquire associations with context that
also supports film items. The intervention can then reduce later film
recall by adding task competitors while stored film-item associations
remain available. Panel B
Figure~\ref{fig-retrieved-context-encoding-associations} summarizes this
encoding claim: the reminder shifts task encoding into film-overlapping
context, so later context-guided retrieval can cue task competitors
alongside film material.

\subsection{Recognition and Supplied Film
Items}\label{recognition-and-supplied-film-items}

The retrieved-context framework distinguishes two routes by which film
material can enter a test response. In context-guided retrieval, the
current state of context cues candidate items, so a film memory is
reported only if film material is selected from the items supported by
that state. In item-guided retrieval, a presented film statement or
still image is already the candidate, so the task is to evaluate the
context retrieved by that item. Trauma-film studies commonly assess
voluntary memory with recognition tests, where participants judge
whether presented film statements or still images appeared in the film
(\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019},
\citeproc{ref-lau2021selectively}{2021};
\citeproc{ref-varma2024experimental}{Varma et al., 2024}). By contrast,
diary and laboratory monitoring tasks ask participants to report film
memories that arise during daily life or during an ongoing task
(\citeproc{ref-holmes2008inducing}{Holmes \& Bourne, 2008};
\citeproc{ref-james2016trauma}{James et al., 2016};
\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019}). A
retrieved-context account therefore interprets the dissociation between
recognition and intrusion-like measures under reminder-linked task
interference as primarily test-format dissociations. Comparisons between
intrusion-like reports and recognition tests confound retrieval
intentionality with the route by which film material is accessed.

Recognition judgments are shaped by the context surrounding a test
probe. Recently studied items are recognized more accurately than less
recent items. Similar lures are harder to reject, and one recognition
probe can influence recognition of items studied nearby
(\citeproc{ref-healey2016four}{Healey \& Kahana, 2016};
\citeproc{ref-jin2024theory}{Jin et al., 2024};
\citeproc{ref-kahana2020computational}{Kahana, 2020};
\citeproc{ref-schwartz2005shadows}{Schwartz et al., 2005}). In
retrieved-context accounts of recognition, a presented probe retrieves
context associated with earlier encounters of that item, and the
retrieved context is compared with the context active during the test
(\citeproc{ref-healey2016four}{Healey \& Kahana, 2016};
\citeproc{ref-jin2024theory}{Jin et al., 2024}). Recency, lure
similarity, and carryover between probes can be explained by changes in
the match between the context retrieved by the probe and the context
used for judgment. Recognition therefore probes memory with an item and
evaluates the context that item retrieves.

Reminder-linked task encoding interferes with diary and monitoring
measures when film-associated context cues non-film competitors. Those
measures count film material only when it is retrieved during daily life
or during a monitoring period. After a film reminder, task events can be
encoded while film-associated context is active. Later, film-associated
context can cue those task events along with film items, reducing the
chance that film material is retrieved. Recognition uses the item-guided
route described above. The tested film item can retrieve associated
context without first being selected from film-associated context.
Figure~\ref{fig-recognition-test-format} formalizes this supplied-item
route: reminder-linked task items remain competitors during
context-guided recall, but they do not compete for the initial
availability of a presented film probe.

Voluntary recall can be tested by means other than recognition. In
vigilance-intrusion tasks, participants perform an ongoing task while
film or foil cues appear, and they report film memories that arise
during the task (\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019},
\citeproc{ref-lau2021selectively}{2021}). A voluntary version can keep
the same film-cued task structure while instructing participants to
search deliberately for film memories, while an involuntary version can
instead more neutrally instruct participants to report any film memories
that come to mind (\citeproc{ref-mcconnell2026testing}{McConnell et al.,
2026}). Both versions score film material retrieved during a recall
period rather than recognition judgments about supplied candidates.

Film cues in these tasks still shape retrieval. A film cue can reinstate
context associated with the cued film material. If recall depends on
maintaining film-associated context across the retrieval period, film
cues can support recall in both monitoring and deliberate-search
conditions. That cue support does not automatically remove
reminder-linked competition. After reminder-linked task encoding, the
reinstated context may also support task material, enabling task items
to compete with film material during context-guided recall. A
recognition probe changes the access route more sharply because the
probe is the candidate item to be judged.

Recognition-intrusion comparisons therefore make confounds test format
and retrieval intentionality in measures of the selective interference
effect. Better-matched recall designs keep film material dependent on
context-guided retrieval across intentionality conditions, with film
cues modeled as inputs to the retrieval context. Under that design,
differences in the effects of reminder-linked task encoding on film
recall can be attributed to the way deliberate recall controls the
course of memory search.

\subsection{Film-Directed Recall Control Under Matched Retrieval
Conditions}\label{film-directed-recall-control-under-matched-retrieval-conditions}

Competitor encoding makes film recall vulnerable when retrieval is
guided by context that supports both film and task candidates. Diary and
vigilance-intrusion measures count film memories when they come to mind,
often during ongoing activity or monitoring rather than after a specific
film item has been supplied (\citeproc{ref-holmes2008inducing}{Holmes \&
Bourne, 2008}; \citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019},
\citeproc{ref-lau2021selectively}{2021}). The most relevant voluntary
comparison similarly requires film material to be called to mind during
a recall period rather than judged as a supplied recognition candidate
(\citeproc{ref-lau2019intrusive}{Lau-Zhu et al., 2019};
\citeproc{ref-mcconnell2026testing}{McConnell et al., 2026}). Under this
matched recall design, a film reminder can make task material accessible
from the same retrieval state as film material by associating task
events with film-overlapping context. Control processes can improve
deliberate recall by orienting retrieval toward the film. They protect
film recall from reminder-linked interference to the extent that they
make retrieval less dependent on film-associated context that also
supports task material.

Within this matched recall setting,
Figure~\ref{fig-retrieved-context-retrieval-operations} separates three
ways deliberate recall can differ from unguided retrieval after the same
reminder-linked task encoding. Start-of-film context reinstatement acts
before sampling by changing the initial context state. A maintained
film-retrieval goal acts during sampling by adding support to film
candidates. Retrieval monitoring acts after sampling by reducing the
carryover from off-target candidates. These control points make
separable predictions because they change different parts of the
retrieval cycle. The simulations test which control changes the effect
of reminder-linked task encoding, rather than simply increasing film
recall under all conditions.

Deliberate recall can begin from a context state biased by retrieval
instructions. When people are asked to recall an earlier studied list
after studying a more recent one, their early responses are often
already biased toward the instructed list rather than showing a gradual
search backward through recent-list items
(\citeproc{ref-healey2024peppr}{Healey \& Wahlheim, 2024};
\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015}). Recall also
shows a reliable tendency to start near the beginning of a studied list,
especially when the usual end-of-list advantage is weakened by a delay
(\citeproc{ref-healey2014memory}{Healey \& Kahana, 2014};
\citeproc{ref-herrema2024first}{Herrema \& Kahana, 2024};
\citeproc{ref-howard1999contextual}{Howard \& Kahana, 1999}).
Start-of-list context reinstatement mechanisms account for these
patterns by evolving the current context toward the state associated
with the beginning of the target list before retrieval begins
(\citeproc{ref-healey2024peppr}{Healey \& Wahlheim, 2024};
\citeproc{ref-kragel2015neural}{Kragel et al., 2015};
\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015};
\citeproc{ref-morton2016predictive}{Morton \& Polyn, 2016}). In our
retrieval control simulations, start-of-film reinstatement drifts the
retrieval state toward the context present at the beginning of film
encoding. This starting state favors early film candidates before
ordinary context-guided sampling resumes, so its predicted benefit is
tied to the temporal region that has been reinstated.

Retrieval monitoring acts after a candidate has been sampled. Evidence
for this post-sampling control comes from externalized recall tasks
where participants report every word that comes to mind and mark errors.
These instructions reveal many more intrusions than standard recall, and
many sampled intrusions are marked as errors, indicating that off-target
candidates can enter retrieval without being accepted as target memories
(\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015};
\citeproc{ref-unsworth2010understanding}{Unsworth et al., 2010}).
Monitoring also carries forward across retrieval: when people fail to
identify one response correctly, they are worse at rejecting the next
intrusion (\citeproc{ref-unsworth2010understanding}{Unsworth et al.,
2010}). At the same time, sampled intrusions can pull search away from
the target list, as intrusions tend to cluster with other intrusions
from related prior-list or semantic contexts
(\citeproc{ref-unsworth2010understanding}{Unsworth et al., 2010};
\citeproc{ref-zaromb2006temporal}{Zaromb et al., 2006}).
Retrieved-context implementations have treated monitoring as a
target-match filter while still allowing rejected items to update the
next retrieval context (\citeproc{ref-lohnas2015expanding}{Lohnas et
al., 2015}). Our trauma-film simulations explore whether that
post-sampling evaluation can also reduce carryover from sampled non-film
candidates. A sampled non-film candidate still counts as a retrieval
attempt, but its context update is dampened when it is evaluated as
off-target. Monitoring can therefore help deliberate recall return to
film material after non-film competition appears, while leaving the
initial competition from reminder-linked task encoding in place.

A maintained retrieval goal gives deliberate recall a broader
film-directed signal during candidate sampling. When people study
mixed-category material and are asked to retrieve only one category,
they can restrict recall to the target subset while temporal
organization remains visible within that subset
(\citeproc{ref-lohnas2026specialized}{Lohnas et al., 2026};
\citeproc{ref-polyn2011semantic}{Polyn et al., 2011}). In this kind of
task, category-selective activity tracks retrieval effort, remains
active between reported recalls, and weakens before extra-category
intrusions (\citeproc{ref-norman2017neuronal}{Norman et al., 2017}).
Retrieved-context models provide a formal precedent for this kind of
non-temporal support: semantic, task, and source information can
contribute to candidate support alongside temporal context
(\citeproc{ref-morton2016predictive}{Morton \& Polyn, 2016};
\citeproc{ref-polyn2009context}{Polyn et al., 2009a},
\citeproc{ref-polyn2009task}{2009b}). Category-directed search has been
formalized in associative memory models, and recent review work treats
this as a natural but still underdeveloped direction for CMR
(\citeproc{ref-lohnas2026specialized}{Lohnas et al., 2026};
\citeproc{ref-raaijmakers1980sam}{Raaijmakers \& Shiffrin, 1980}). The
simulations use this logic in reduced form by adding a maintained
film-category cue during candidate sampling. This cue gives film
candidates additional support without equally supporting task
competitors. Task items encoded in film-overlapping context can still
compete through temporal context, but they do not receive this
goal-based support.

A retrieval-control process can increase film recall relative to
unguided retrieval without making recall less sensitive to a
reminder-linked task intervention. Protection depends on whether recall
becomes less reliant on film-associated temporal context after that
context has also become supportive of task material. The start-state and
monitoring panels describe mechanisms that either reinstate or preserve
film-associated context to drive ongoing retrieval, but since
reminder-linked task encoding makes that context less selective, those
mechanisms cannot substantially protect deliberate recall from the
interference effect. The maintained film-retrieval goal tests that
different route. It gives film candidates support from a film-specific
cue, so task competitors remain available but do not receive the same
added support. Under the tested conditions, that goal-based support
limits the intervention's impact enough to simulate a
selective-interference effect. The simulations therefore treat increased
film recall and reduced sensitivity to reminder-linked task encoding as
separable outcomes.

\section{Model Specification}\label{model-specification}

Retrieved-context models implement recall as a sequence of sampling
events in which current context gives graded support to candidate items
(\citeproc{ref-polyn2009context}{Polyn et al., 2009a};
\citeproc{ref-sederberg2008context}{Sederberg et al., 2008}). To express
selective interference as changes in what gets sampled, film and
non-film events have to be candidates in the same sampling process. The
simulations implement this requirement by representing film, task, and
delay periods as sequences of events that update context. For the film,
these events correspond roughly to scenes or segments. For the task
periods, they represent task items that can become competitors after
reminder-linked encoding. For the delay periods, they represent filler
items: non-film events that can also be encoded and later sampled.
Interference manifests as a shift in sampled outcomes: task or filler
candidates occupy sampling events that could otherwise retrieve film
material.

The formal model links this sampling process to separate item and
context representations. Each encoded event at position \(i\) is
represented by an item feature vector \(f_i\), a one-hot vector that
distinguishes that event from other encoded events in the simulated
paradigm. Context \(c_i\) denotes the internal context state after event
\(i\) has updated context. As film, task, and filler events occur, they
update context and become associated with the context active around
them. During recall, the current context state determines which
candidate items receive support.

During encoding, items and states of context are linked through
bidirectional associations represented in two matrices.
Context-to-feature memory, \(M^{CF}\), maps context states to item
support, allowing current context to cue candidate items during recall.
Feature-to-context memory, \(M^{FC}\), maps item features to context
states so that cued, reminded, or recalled items can reinstate
associated context. All vectors are treated as column vectors, so
\(M^{FC} f_i\) is a context vector and \(M^{CF} c_i\) is a
feature-support vector.

Context and corresponding associations are further subdivided into
temporal and source components. Temporal context distinguishes unique
items so different film, task, and filler events can produce distinct
context states even if items come from the same phase of the paradigm or
share other features. Source context represents coarser information
shared across related events, allowing recall to be shaped by task,
semantic, or source relationships among items
(\citeproc{ref-polyn2009context}{Polyn et al., 2009a},
\citeproc{ref-polyn2009task}{2009b}). Emotional CMR variants distinguish
emotional from neutral material in source context and give emotionally
salient items stronger source-context associations
(\citeproc{ref-cohen2022memory}{Cohen \& Kahana, 2022};
\citeproc{ref-talmi2019retrieved}{Talmi et al., 2019}). In the present
implementation, each item also has a source feature vector \(s_i\). Film
items share a film-source feature, whereas task and filler items carry a
neutral/default source feature.

\subsection{Encoding the Paradigm
Sequence}\label{encoding-the-paradigm-sequence}

Film, task, and filler events become later recall candidates through
context updating and item-context learning. Each event updates context
and becomes associated with the resulting state. During later recall,
candidate support depends on how strongly studied items are associated
with the context states active during retrieval.

Before the simulated film starts, context is initialized to \(c_0\), a
start state with no item-associated context units active. Memory
matrices are initialized with pre-experimental associations that reflect
baseline structure already present before the simulated paradigm begins.
In \(M^{FC}\), each item \(i\) can cue its paired context unit with
weight \(1-\gamma\). In \(M^{CF}\), each item is most strongly supported
by its paired context unit, with weight \(\delta\). The other
item-associated context units provide weaker background support to that
item, with weight \(\alpha\). The start state \(c_0\) initially provides
no item support in \(M^{CF}\). The initial entries of \(M^{FC}\) and
\(M^{CF}\) are therefore:
\begin{equation}\phantomsection\label{eq-mfc-pre}{
M^{FC}_{pre}(j,i) =
\begin{cases}
1 - \gamma & \text{if } j = i + 1 \\
0 & \text{otherwise}
\end{cases}
}\end{equation}

\begin{equation}\phantomsection\label{eq-mcf-pre}{
M^{CF}_{pre}(i,j) =
\begin{cases}
0 & \text{if } j = 0 \\
\delta & \text{if } j = i + 1 \\
\alpha & \text{if } j > 0 \text{ and } j \neq i + 1
\end{cases}
}\end{equation}

When event \(i\) is encountered, its representation \(f_i\) retrieves
context input through feature-to-context memory:

\begin{equation}\phantomsection\label{eq-context-input}{
c_i^{\mathrm{IN}} = M^{FC} f_i .
}\end{equation}

Context then drifts toward the normalized input. The coefficient
\(\rho_i\) keeps context normalized after the update:

\begin{equation}\phantomsection\label{eq-context-update}{
c_i = \rho_i c_{i-1} + \beta_{\mathrm{enc}} \widehat{c}_i^{\mathrm{IN}} .
}\end{equation}

Each event also encodes associations between its item features and the
current context state. Feature-to-context learning updates \(M^{FC}\) so
later cues or sampled items can reinstate associated context:

\begin{equation}\phantomsection\label{eq-mfc-learning}{
\Delta M^{FC} = \gamma c_i f_i^\top .
}\end{equation}

Context-to-feature learning updates \(M^{CF}\) so later context can
support the item during sampling:

\begin{equation}\phantomsection\label{eq-mcf-learning}{
\Delta M^{CF} = \lambda \phi_i f_i c_i^\top .
}\end{equation}

Here, \(\gamma\) controls feature-to-context learning while \(\lambda\)
scales context-to-feature learning. To capture primacy effects in
recall, the scale \(\phi_i\) boosts context-to-feature learning for
early items in the paradigm and decays across subsequent items.

Encoding events also have a source feature vector \(s_i\) that
distinguishes film items from non-film items. The source component of
context follows the same normalized-drift form as temporal context, with
source drift rate \(\beta_{emot}\). All items can form associations with
the source context active for that event, scaled by a baseline
source-learning term \(\eta_s\). For film encoding events, the
source-context portion of the context-to-feature update receives an
additional \(\phi_{\mathrm{emot}}\) scale to reflect stronger encoding
of emotional material in the trauma-film paradigm
(\citeproc{ref-cohen2022memory}{Cohen \& Kahana, 2022};
\citeproc{ref-talmi2019retrieved}{Talmi et al., 2019}). Task and filler
events carry the neutral/default source feature, so they use the
baseline source-learning scale without the added film-source term. After
encoding, film, task, and filler candidates can all enter later recall
through the temporal and source-context associations learned for each
item.

\subsection{Reminder-Linked Task
Encoding}\label{reminder-linked-task-encoding}

After the film-delay period, the simulated paradigm can present film
reminders before the task begins. The reminder phase reinstates
film-associated context before task items are encoded. Task items
encoded from that state can later receive support for recall from
context that also supports film material.

The reminder phase begins by updating context toward the start state of
the film sequence. Let \(c_b\) denote the context state after the break
period. The reminder-phase start update is:

\begin{equation}\phantomsection\label{eq-reminder-start-update}{
c_{r,0} = \rho_{r,0} c_b + \beta_{\mathrm{rem,start}} c_0 .
}\end{equation}

The model then applies a sequence of film-item reminder cues. Each item
from the film phase is presented as a reminder cue in the order it was
encoded. Feature-to-context memory retrieves reminder input as in
Equation~\ref{eq-context-input}, and context drifts toward that input
using the normalized update in Equation~\ref{eq-context-update} with the
reminder drift rate. Reminder cues update context but do not become
recallable items and do not add new context-to-feature learning. This
isolates the reminder's effect to reinstating film-associated context
rather than adding new film-item associations.

Task events are then encoded by the ordinary event-learning rules with
the reminder-updated context as the starting state. Task items carry the
neutral/default source feature rather than the film-source feature, so
they do not receive the added \(\phi_{\mathrm{emot}}\) term. To
represent stronger or weaker task encoding, the simulations scale
context-to-feature learning for task events by a task-encoding-strength
factor \(m_{\mathrm{task}}\):

\begin{equation}\phantomsection\label{eq-task-mcf-learning}{
\Delta M^{CF}_{\mathrm{task}} = m_{\mathrm{task}} \lambda \phi_i f_i c_i^\top .
}\end{equation}

Task items become interfering competitors in later recall because they
become associated with context states that can cue film material. The
intervention therefore changes how non-film items are cued by
film-associated context, without weakening the film-item associations
formed during film encoding.

\subsection{Context-Guided Recall and Test-Phase
Cues}\label{context-guided-recall-and-test-phase-cues}

In recall formats where film material must come to mind before it can be
reported, the current context state assigns support to film, task, and
filler candidates. At sampling step \(j\), candidate support is computed
by probing context-to-feature memory with the full context state:

\begin{equation}\phantomsection\label{eq-recall-support}{
a_{i,j} = [M^{CF} c_j]_i .
}\end{equation}

The context vector \(c_j\) includes both temporal and source-context
components. Candidates already sampled in the current recall period are
excluded from later sampling.

Sampling follows a Luce choice rule over the remaining candidates
(\citeproc{ref-luce1959individual}{Luce, 1959}):

\begin{equation}\phantomsection\label{eq-luce-choice}{
P(i \mid \mathrm{continue}) =
\frac{a_{i,j}^{\tau}}{\sum_{\mathrm{remaining}\ k} a_{k,j}^{\tau}} .
}\end{equation}

Following likelihood-based CMR implementations, stopping is modeled as a
position-dependent hazard independent of current candidate support
(\citeproc{ref-kragel2015neural}{Kragel et al., 2015};
\citeproc{ref-morton2016predictive}{Morton \& Polyn, 2016}):

\begin{equation}\phantomsection\label{eq-stopping}{
P_{\mathrm{stop}}(j) = \theta_s e^{j\theta_r}.
}\end{equation}

This value is bounded to remain a valid probability. Because stopping is
independent of candidate support, interference is read from the identity
of sampled items. A sampled task or filler item takes the place of a
possible film sample.

After a candidate is sampled, feature-to-context memory updates context
toward the sampled item's associated context:

\begin{equation}\phantomsection\label{eq-recall-context-update}{
c_{j+1} =
\rho_{\mathrm{rec},j} c_j +
\beta_{\mathrm{rec}} \widehat{M^{FC} f_{r_j}} .
}\end{equation}

This update lets sampled material shape later search. A sampled film
item can keep later sampling near film-associated context. A sampled
task or filler item can pull later sampling toward non-film material.

Test-phase film cues use the same feature-to-context operation without
becoming recall outputs. When a film cue \(q\) is presented, the cued
item updates context through \(M^{FC} f_q\). The cue is not counted as a
recalled item, does not make the cued film item unavailable for later
recall, and adds no new learning. Recall sampling then resumes from the
updated context state.

\subsection{Deliberate Recall Control}\label{deliberate-recall-control}

Deliberate recall uses the same sampling rule as unguided recall, with
control settings applied before, during, or after sampling. The control
settings change the retrieval cue, candidate support, or sampled-item
carryover without changing the film and task associations learned during
encoding. This lets the simulations test which retrieval operations
increase film recall and which ones protect film recall from
reminder-linked task competition.

Start-of-film context reinstatement drifts context toward the state
present at the beginning of film encoding before the first sampling
step. The retrieval context is drifted toward the context state used to
begin the film sequence, with drift rate \(\beta_{\mathrm{start}}\).
This can bias early sampling toward film candidates rather than starting
from the ongoing context state produced by the final delay phase of the
paradigm. This control mechanism can therefore increase film recall.
However, because it still relies on film-associated context to cue
candidates, it does not substantially protect deliberate recall from the
interference effects of reminder-linked task encoding.

In retrieved-context models of externalized free recall, monitoring is
implemented as a post-sampling match check: rejected candidates are
withheld as target responses but still update the next retrieval context
(\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015}). The present
simulations keep the post-sampling timing but change the consequence of
sampled non-film candidates. Post-retrieval context monitoring reduces
the context update after sampled task or filler candidates. Let
\(\kappa_i = 1\) for film candidates and \(\kappa_i = \kappa\) for task
and filler candidates. With monitoring, the sampled-item update becomes:

\begin{equation}\phantomsection\label{eq-monitoring-update}{
c_{j+1} =
\rho_j(\kappa_i \beta_{\mathrm{rec}}) c_j +
\kappa_i \beta_{\mathrm{rec}} \widehat{M^{FC} f_{r_j}} .
}\end{equation}

When \(\kappa < 1\), sampled non-film candidates still count as sampled
outputs but context is updated less strongly toward their associated
context. This reduces carryover from sampled task or filler candidates
without changing the candidate support that made them available. Like
start-of-film reinstatement, this operation does not by itself remove
task support from film-associated context.

The maintained film-retrieval goal is specified as a retrieval-stage
film-category cue. This term abstracts the kind of semantic or category
support used in retrieved-context models of selective recall, rather
than updating temporal or source context during retrieval
(\citeproc{ref-morton2016predictive}{Morton \& Polyn, 2016};
\citeproc{ref-polyn2011semantic}{Polyn et al., 2011}). The goal adds
support to candidates marked as film items during sampling:

\begin{equation}\phantomsection\label{eq-film-goal-support}{
a^{\mathrm{goal}}_{i,j} = a_{i,j} + \omega_{\mathrm{goal}} g_i .
}\end{equation}

Here, \(g_i = 1\) for film candidates and \(g_i = 0\) for task and
filler candidates. The indicator \(g_i\) is a retrieval-control cue,
distinct from the source feature vector \(s_i\) used during encoding.
Task items encoded in film-overlapping context can still compete through
\(a_{i,j}\), but they do not receive the film-category increment.
Therefore, unlike start-of-film reinstatement and post-sampling
monitoring, the maintained film-retrieval goal can reduce the impact of
reminder-linked task encoding on film recall.

The three evaluated control mechanisms therefore enter the same
retrieval cycle at different points: start-state reinstatement before
sampling, film-category support during sampling, and monitoring after
sampling.

\subsection{Supplied-Item Recognition}\label{supplied-item-recognition}

Recognition begins with a supplied candidate item rather than a sampled
recall candidate. A presented film item retrieves associated context
through the same feature-to-context associations used by reminders,
cues, and sampled items. Following retrieved-context accounts of
recognition, recognition evidence is the match between the context
retrieved by the probe and the context active during the test
(\citeproc{ref-healey2016four}{Healey \& Kahana, 2016};
\citeproc{ref-jin2024theory}{Jin et al., 2024};
\citeproc{ref-lohnas2015expanding}{Lohnas et al., 2015}):

\begin{equation}\phantomsection\label{eq-recognition-evidence}{
e_q = (M^{FC} f_q)^\top c_{\mathrm{test}} .
}\end{equation}

The simulations use this evidence as a supplied-item access step rather
than a full recognition-decision model. A recognition probe can update
context after evidence is scored, but it is not treated as a recalled
output. It does not enter the recallable candidate set, make the probed
item unavailable for later recall, or add new learning. This implements
the focal distinction between recognition and context-guided recall
measures in the trauma-film paradigm: recall requires film material to
be selected from context-supported candidates, whereas recognition
starts with the candidate item and evaluates the context it retrieves.

\section{Simulations}\label{simulations}

The simulations instantiate the retrieved-context account by mapping the
trauma-film paradigm onto sequences of film, delay, task, and filler
events. Simulation 1 shows how a task performed after a film reminder
attenuates film recall when task encoding is strong and occurs in
context states that overlap with film encoding context. Simulation 2
adds the intentionality manipulation by contrasting unguided retrieval
with deliberate recall and examining control mechanisms that could
protect film recall. The recognition simulation then examines a boundary
case in which the test supplies a candidate film item for judgment
rather than requiring that item to be sampled from context. Together,
these simulations show how selective interference can arise from
reminder-linked competitor encoding and retrieval conditions that differ
in how they access or support film material.

\subsection{Methodology}\label{methodology}

The simulations require default values for context drift, associative
learning, sampling, and stopping before the trauma-film manipulations
are applied. Estimating those values from selective-interference data
would require the full modeled paradigm together with trial-by-trial
recall sequences that identify which film, task, and non-film candidates
entered retrieval. Existing trauma-film studies define the target
phenomenon, but they typically report intrusion counts or final memory
scores rather than the sequence-level data needed to estimate retrieval
competition. We therefore use an immediate affective free-recall dataset
to set the model's core encoding, retrieval, and stopping parameters.

In that dataset, participants who reported concern about the war in
Ukraine studied and recalled lists of war-related and neutral
photographs (\citeproc{ref-dupertuys2026ukraine}{Dupertuys et al.,
2026}). The fitted dataset included 123 participants, four lists per
participant, 492 immediate recall sequences, and 3,804 scored recall
events. Parameters were estimated from the ordered recall sequences
using the model likelihood, yielding a pooled parameter regime rather
than separate fits to the selective-interference simulations. The
resulting parameter values provide a starting regime for context-guided
recall of affective and neutral photographs.

The selective-interference simulations then add the trauma-film phase
structure, reminder manipulation, task-encoding manipulation, and
retrieval-control settings. Additional implementation settings adapt
this regime to the trauma-film sequence. Film items reinstate the marked
source feature into source context, neutral/default events can weakly
bind active source context, and retrieval begins with partial
film-source reinstatement. The primacy profile is also moderated
relative to the immediate-recall fit so that the shorter film sequence
is not dominated by an unrealistically steep first-item advantage.

used in the simulations.

In all simulations, the model first encodes the paradigm events and then
enters retrieval. Film, break/buffer, task, and filler items are encoded
by the CMR operations defined above. Each simulated trial contains 16
film items, 16 break/buffer items, 16 task items, and 16 filler items
unless otherwise noted. Break/buffer items implement the delay before
the reminder or task, and filler items implement the post-task delay.
Equal phase lengths make redistribution across film, task, and filler
periods directly comparable.

Reminder cues and test-phase film cues update context through
Equation~\ref{eq-context-input} and Equation~\ref{eq-context-update},
but they do not add recallable items or new item-context learning.
Simulations that present candidate item information in a different test
format specify that route separately. In context-to-item recall
simulations, all encoded film, break/buffer, task, and filler items can
enter the retrieval competition. Retrieval allows up to 48 sampling
steps, and sampled items are removed from the candidate set so the same
item is not sampled twice. The simulated retrieval sequence records
sampled candidates by type and encoded position, rather than only final
film counts. This convention makes it possible to examine predictions
about how interference redistributes recall across the encoded stream,
rather than only reporting final recall counts.

Parameter sweeps rerun the full encode-then-retrieve simulation across
planned values of a manipulated parameter. For each condition and
manipulated parameter value, the model first completes the phase
sequence, then enters retrieval and samples recallable items using
Equation~\ref{eq-luce-choice} and Equation~\ref{eq-stopping}. This
procedure is repeated across simulated trials within each cell. When
figures plot recall across the encoded stream, they summarize retrieval
after the full phase sequence has been encoded. Serial-position curves
plot the proportion of trials in which each encoding position was
retrieved, and phase summaries average those proportions within each
phase. Thus, position and phase labels identify encoding positions,
whereas recall probabilities refer to subsequent retrieval.

\subsection{Simulation 1: Task Encoding and Contextual
Overlap}\label{simulation-1-task-encoding-and-contextual-overlap}

Simulation 1 tests whether reminder-linked task encoding can create
competitors for unguided film recall. Retrieval settings are held fixed,
so differences across conditions reflect associations formed before
retrieval rather than deliberate control. The design crosses pre-task
reminder presence with task encoding strength while weak film cues are
supplied periodically during recall in all conditions. In the
no-reminder condition, the reminder-start and film-cue drift scales are
set to zero. In the with-reminder condition, context first shifts toward
the start state and then receives sequential film reminder cues before
task encoding. Reminder cues update context without applying
Equation~\ref{eq-mfc-learning} or Equation~\ref{eq-mcf-learning} and
without adding recallable items. Task encoding strength is modeled as a
multiplier on task-phase context-to-feature learning in
Equation~\ref{eq-mcf-learning}.

\subsection{Simulation 2: Control Mechanisms for Deliberate
Recall}\label{simulation-2-control-mechanisms-for-deliberate-recall}

Simulation 2 examines the conditions under which deliberate film recall
is protected from reminder-linked task competition. The simulation keeps
the same reminder-by-task-encoding design and periodic film cues, but
varies retrieval mode and decomposes the control operations available
during deliberate recall. Deliberate recall combines three control
operations: start-of-film context reinstatement before sampling, a
maintained film-retrieval goal during sampling, and post-retrieval
context monitoring after sampled non-film items. The main readout is the
film-recall loss produced by strong task encoding after a film reminder,
not only total film recall.

Figure~\ref{fig-simulation2-start-context-reinstatement} holds the
high-interference condition fixed and isolates start-of-film context
reinstatement. Reinstatement increases access to early film positions
and shifts the first sampled item toward the beginning of the film
sequence. Those gains persist in the full recall curve, but later film
positions remain vulnerable because the start state does not remove task
support from film-overlapping context. Start-of-film context
reinstatement can increase film recall, but its protection depends on
which part of the film trajectory is reinstated.

Retrieval monitoring acts after a non-film item has already been
sampled. By dampening that item's context update, monitoring limits how
much the sample redirects subsequent retrieval.
Figure~\ref{fig-simulation2-target-monitoring-diagnostic} shows that
monitoring increases the probability that a sampled non-film item is
followed by a film output. Monitoring therefore helps recall recover
after task or filler material has entered the output sequence. It does
not supply film-directed support before sampling occurs, so it is not
the broadest route to protection from reminder-linked task competition.
Simulation 2 therefore constrains the account: deliberate recall is not
spared by a generic voluntary-memory setting. It is less affected when
control supplies film-directed support that task competitors do not
share, whereas controls that only change retrieval initiation or
post-sampling carryover remain more vulnerable.

\subsection{Simulation 3: Recognition}\label{simulation-3-recognition}

The recognition simulation asks what happens when the test presents the
candidate film item rather than requiring that item to be sampled from
context. The same reminder-by-task-encoding design is used, but the test
format changes how film material enters the response. Context-guided
recall requires a film item to be sampled from the candidates supported
by current context. Recognition begins with a supplied candidate item
and asks whether the context retrieved by that item supports its
occurrence in the film.

The simulation presents studied film items and unstudied film-like foils
as recognition probes. Each probe retrieves associated temporal and
source context through feature-to-context associations, and recognition
evidence is computed from the match between the probe-retrieved context
and the current test context (\citeproc{ref-healey2016four}{Healey \&
Kahana, 2016}; \citeproc{ref-jin2024theory}{Jin et al., 2024}). The
simulation estimates recognition evidence after the candidate item has
already been presented as a probe. Decision criteria, confidence, and
detailed foil-processing assumptions are left outside the present
implementation.

\begin{figure}[H]

\caption{\label{fig-recognition-test-format}\textbf{Item-to-context
retrieval bypasses reminder-linked task interference.} \textbf{(A)} CMR
stores bidirectional associations between item features and context.
Feature-to-context memory lets an available item reinstate its
associated context, whereas context-to-feature memory lets context cue
candidate items. \textbf{(B)} When film-associated context cues items,
film items and reminder-linked task items can both receive support. When
a film item reinstates context, retrieval targets context units instead,
so task items are not competitors in that step. \textbf{(C)} In
recognition, the tested film item is already available. The item
retrieves associated context, which is compared with ongoing test
context; stronger matches provide stronger evidence that the item
appeared in the film. \textbf{(D)} Film recognition accuracy is plotted
across the same reminder and task-encoding conditions used in the recall
simulations. Accuracy is hit rate minus false-alarm rate for unstudied
film-like lures. The reminder-plus-strong-task condition does not
produce a corresponding reduction in recognition accuracy.}

\centering{

\pandocbounded{\includegraphics[keepaspectratio]{work/simulation4_recognition_full_figure/item_context_recognition.png}}

}

\end{figure}%

Figure~\ref{fig-recognition-test-format} shows the resulting test-format
consequence. The reminder-plus-strong-task condition that strongly
reduces context-guided film recall does not produce a corresponding
reduction in recognition accuracy. Corrected recognition remains
essentially unchanged across the reminder-by-task-encoding design,
ranging from .397 to .399. In context-guided recall, film and task
candidates can compete whenever the retrieval context supports both.
Recognition reverses that access route: the presented film candidate
retrieves associated context directly, so task items do not compete to
be retrieved in place of the film item. The simulation therefore
identifies a test-format confound in designs that compare involuntary
tests measuring whether film material comes to mind with voluntary tests
that supply film material for recognition. Such designs therefore do not
isolate retrieval intentionality: preserved recognition alongside
reduced intrusions may reflect the supplied-item test format rather than
a general sparing of voluntary recall.
